# Toktopus v1.7.0: Local observability and Model Health

Toktopus now keeps local session history, displays observed tool timelines, imports OpenTelemetry trace metadata, and shows cached LiveNerf results in the terminal. No monitoring-service login, API key, cloud backend, or model call is required.

## Added

- Persistent SQLite history with metadata search, bounded retention, and session selection.
- History and timeline paging in the dashboard. Use J for History, brackets to select a session, Enter for its timeline, and N/P to move between pages.
- Observed tool status, available UTC timestamps, failure grouping, and repeated-tool activity hints.
- Automatic collection from detected local agents every five seconds, with two-second caching for selected-agent telemetry.
- Local OTLP JSON file imports with span identity, parent relationships, available token counters, timestamps, and measured duration. Missing fields remain unavailable.
- A Model Health view powered by public LiveNerf results. Refresh is explicit; ordinary viewing uses a validated local cache. Source URL, retrieval time, content digest, CLI version, and harness metadata remain inspectable.
- Diagnostics for missing sources, unsupported schemas, and local reader failures.
- Support for OpenCode's session/message/part database schema, alongside the legacy reader.
- A module entry point: `python -m toktopus` works when Python's scripts directory is not on PATH.

## Corrected

- Account quota displays no longer compare cumulative session tokens with fictional minute limits.
- Codex input/cache and output/reasoning subsets are no longer double-counted in session totals and estimated costs.
- Codex and GitHub Copilot are no longer treated as the same product.
- Fabricated token speeds and Pi fallback activity have been removed.
- OpenCode session totals are no longer presented as current context occupancy.
- Native Claude and Codex tool calls are paired with available results, including custom Codex tools. Unconfirmed operations remain observed rather than being marked successful.
- ISO timestamps in Claude records are handled correctly.
- Explicit requests for a missing Codex session no longer display another session's rollout data.
- Repeated polling updates stored snapshots and events rather than inflating usage.
- Local history failures display actionable status instead of terminating history navigation.
- Package discovery now excludes tests, research checkouts, and development scripts from release wheels.
- Immediate dashboard refresh no longer depends on a platform's monotonic clock starting value.
- CI uses a compatible Ubuntu image for Python 3.9 and current GitHub Actions runtimes.

## Privacy and cost

History stores selected metadata and omits prompts, tool arguments, tool outputs, and arbitrary imported attributes. Records remain on the local machine. Use `--no-history` to disable recording and automatic background discovery for a run.

Normal monitoring makes no model requests and adds no inference charges. Existing coding-agent subscriptions and API usage still have their usual costs. LiveNerf refresh downloads public results; it does not run a benchmark or consume model credits.

## Compatibility notes

- Requires Python 3.9 or newer.
- JSON exports now use null for unavailable account-limit fields and explicitly unavailable context or throughput values. Update consuming scripts that assume these fields are always numbers.
- Billing exports include an estimate source and `actual_billed_usd: null`. An estimate is not a provider invoice.
- New configurations default to automatic agent selection. Existing saved agent choices remain in effect.
- History is recorded while Toktopus runs. Complete historical reconstruction, project/task maps, broader native parsers, subagent correlation, and live SDK/hook bridges remain future work.
- The OTLP importer accepts bounded JSON files, not protobuf streams, and does not start a network collector.
- Upstream LiveNerf results do not establish the quality of an individual session. Toktopus does not infer a degradation verdict or sum overlapping aggregate/family rows.

## Install or update

```bash
python -m pip install --upgrade "git+https://github.com/NadimHider/toktopus.git@v1.7.0"
python -m toktopus
```

Git is required for that command. Alternatively, download the attached wheel and run `python -m pip install --upgrade PATH_TO_WHEEL`. A source distribution and SHA-256 checksums are attached as well.

## Validation

The release passes 111 local unit and integration tests, Ruff lint, and distribution builds on Windows with Python 3.14. GitHub Actions runs the test suite across Linux, Windows, and macOS on Python 3.9 through 3.13, with an additional lint and build job.

## Try the new views

```bash
python -m toktopus --history
python -m toktopus --history --search codex --limit 20
python -m toktopus --timeline SESSION_ID --agent codex
python -m toktopus --diagnostics --agent opencode
python -m toktopus --import-otlp trace.json
python -m toktopus --refresh-model-health
```
