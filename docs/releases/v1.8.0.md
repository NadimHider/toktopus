# Toktopus v1.8.0: Live BenchLM REST API Integration

Toktopus now integrates with the official BenchLM REST API (`data.benchlm.ai`), replacing static benchmark lists with live AI coding model rankings, token pricing, multiple ranking surfaces, atomic local caching, and offline fallback.

## Added

- **Live BenchLM REST API Integration**: Directly queries `https://data.benchlm.ai/v1/rankings/current` to display real-time coding benchmark rankings and composite BenchAlign scores.
- **Token Pricing Synchronization**: Pulls live input and output token pricing from `https://data.benchlm.ai/v1/pricing` across 400+ models, with seamless fallback to Toktopus's local pricing table.
- **Ranking Surface Selection**: Added `--surface {coding,agentic,reasoning,overall}` to query and display specialized benchmark leaderboards (defaults to `coding`).
- **Atomic Local Caching & Freshness TTL**: Caches benchmark snapshots locally in `~/.config/toktopus/benchlm.json` and `benchlm_{surface}.json` with a 24-hour freshness TTL and atomic file replacement.
- **Offline & Failure Resilience**: When offline or if an API refresh fails, Toktopus automatically preserves the last valid cache or falls back to bundled defaults without hanging or degrading the live terminal dashboard.
- **Configurable BenchLM Authentication**: Added `benchlm_api_key` setting in `config.json`, `--benchlm-key <KEY>` CLI argument, and environment variable support (`BENCHLM_API_KEY`, `BENCHLM_DATA_KEY`).
- **Explicit Benchmark Refresh**: Added `--refresh-benchmarks` flag to fetch the latest model rankings and update local cache on demand.
- **TUI Dashboard Source Provenance**: Pressing <kbd>B</kbd> in the dashboard displays live source branding (`BenchLM Live` vs `BenchLM Cached` vs `Bundled Index`) and verification timestamps.
- **Comprehensive Test Suite**: Added `tests/test_benchlm.py` covering ranking normalization, pricing integration, offline cache recovery, stale detection, and model resolution.

## Compatibility notes

- Requires Python 3.9 or newer.
- Retains 100% backward compatibility with existing command flags, telemetry snapshots, and history storage.
- If no BenchLM API key is configured or internet access is unavailable, Toktopus continues to serve the bundled offline benchmark index without errors.

## Install or update

```bash
python -m pip install --upgrade "git+https://github.com/NadimHider/toktopus.git@v1.8.0"
python -m toktopus
```

Git is required for that command. Alternatively, download the wheel and run `python -m pip install --upgrade PATH_TO_WHEEL`.

## Validation

The release passes 118 unit and integration tests across Linux, Windows, and macOS on Python 3.9 through 3.13.

## Try the new views

```bash
# View coding model benchmarks (from live BenchLM or local cache)
toktopus --benchmarks

# Force refresh coding rankings from BenchLM REST API
toktopus --refresh-benchmarks

# Query and cache the agentic surface rankings
toktopus --refresh-benchmarks --surface agentic

# View cached agentic benchmarks
toktopus --benchmarks --surface agentic

# Save a BenchLM API key
toktopus --benchlm-key YOUR_API_KEY
```
